# traffic-light-simulator
Traffic Light Simulator

This is a hands-on front-end project where you can play around with a virtual traffic light. Hit “Stop,” “Ready,” or “Go,” and you’ll see both the button and the matching light in the signal box light up.

Features

- Instant feedback: When you click a control, the button and the right light both highlight so it’s clear what’s active.
- Smart state handling: If you pick a new signal, the other lights automatically dim—just like a real traffic light.
- Clean, responsive layout: Thanks to Bootstrap 4’s Flexbox tools, everything stays centered and looks good on any screen.
- Fresh look: The project uses Google Fonts and smooth color transitions for a modern feel.

Tech Stack

- HTML5 for the structure.
- CSS3 for the round signal lights and custom button styles.
- Bootstrap 4 for layout and spacing.
- Pure JavaScript for the interactive parts.

How It Works

JavaScript ties everything together. Each button runs its own function:

- buttonStop() turns the light red.
- buttonReady() switches it to yellow.
- buttonGo() changes it to green.

That’s it — simple, interactive, and easy to use.
